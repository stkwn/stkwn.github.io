Obsidian完全入门之十八：跨设备同步最佳实践：iCloud 与 Remotely Save + 腾讯云

发表于2025-09-01|更新于2025-09-01|notes
|浏览量:

1 Obsidian同步有点痛

说起Obsidian，我被问得最多的是同步的问题。

毕竟，Obsidian作为一款笔记软件，虽然有无数的优点，但也有个致命的缺点：那就是同步，想说爱你不容易。

当然，如果你有米，一切都不是问题，毕竟官方的同步服务Obsidian Sync，就是一键解决的方案。但一个月8美金的价格，对于大多数人来说，不是有点贵，而是不可承受之贵啊。

所以我也从来没用过官方的同步服务，而是在探索免费的同步方案。

今天，我就来和大家分享一下，2种我觉得相对便宜、相对简单的方案，也是经过验证的稳定路线：iCloud 和 Remotely Save + 腾讯云 COS。无论你是苹果全家桶，还是安卓混合，亦或三端使用，都能快速找到合适的落地方案。

2 方案 A：iCloud

如果你是苹果全家桶用户，或者Windows电脑+苹果手机或者Ipad平板，iCloud无疑是最简单的方案。 毕竟，苹果设备自带iCloud功能，设置起来也非常方便。所以可以无脑选择这个方案。

2.1 苹果设备中的iCloud设置

首先，你需要确保你的苹果设备都登录了同一个Apple ID，并且开启了iCloud Drive功能。点击设置，然后找到你的Apple ID，选择iCloud，同时确保iCloud云盘已经开启。

2.2 下载Obsidian移动端，并创建库

然后，你需要在你的iPhone或者iPad上下载Obsidian移动端应用。打开应用后，选择“打开另一个库”，然后选择“从iCloud Drive打开”。

第一次打开软件的时候，会直接跳出创建仓库的窗口。如果你已经有本地库，可以选择管理仓库。因为我们要新建一个放在iCloud的库。

选择创建新的仓库，命名，并打开保存到iCloud云盘的开关。

这时候的云盘里，就已经有了这个名字的文件夹了。（当然了，这个文件夹里面没有东西，只有Obsidian的初始配置文件）

2.3 电脑端打开iCloud里的Obsidian库

2.3.1 Windows电脑

如果你是Windows电脑用户，你需要先安装iCloud for Windows。安装完成后，登录你的Apple ID，并确保iCloud Drive已经开启。

当你做完这两步的时候，就可以在我的iCloud云盘。里面看到刚才在手机上创建的Obsidian文件夹了。

你可以把你在电脑里的Obsidian库，直接移动到这个文件夹里。等iCloud同步完成后，你就可以在手机上看到这些文件了。

2.3.2 Mac电脑

在Mac电脑用户，iCloud Drive也已经集成在系统里了。你只需要打开在侧边栏找到iCloud云盘，同样可以看到你的Obsidian文件夹了。剩下的就是安装Obsidian打开库即可。

2.4 测试同步

现在，你可以在手机上创建一个新的笔记，看看它是否会自动同步到你的电脑上。反之亦然。这是在笔记本里的样式，大家觉得怎么样呢？

### 2.5 注意事项
  • 初次设置：在创建新Vault的时候，最好从移动端开始，而不是从电脑端。否则，很可能会出现同步的问题。Obsidian仓库存储在iCloud云盘上的Obsidian文件夹里，这是不能被修改的。但你可以在这个文件夹里创建多个库。
  • 存储空间：iCloud提供5GB的免费存储空间，如果你的笔记库比较大，可能需要购买更多的存储空间。一般50G的空间，价格是每个月6人民币。
  • 同步速度：iCloud的同步速度通常比较快，但有时可能会有延迟，特别是在网络状况不佳的时候。
  • 文件冲突：如果你在不同设备上同时编辑同一个文件，可能会导致文件冲突。iCloud通常会保留多个版本，但最好避免这种情况。
  • 备份：虽然iCloud会同步你的文件，但建议你定期备份你的Obsidian库，以防数据丢失。

3 方案B：Remotely Save + 腾讯云 COS

如果你的情况比较复杂，特别是涉及到安卓设备。由于安卓设备并没有一个统一的同步方案，也没有像iCloud这样自带的云盘服务，所以我们需要借助第三方的云存储服务来实现同步。

例如我的情况是： Windows电脑 + 苹果手机 + Vivo Pro平板。要实现这样的一个同步方案，我觉得最好用、最便宜、最容易的方案就是：Remotely Save + 腾讯云 COS。

当然了，还有个免费方案，就是利用GitHub来同步。这个方案完全免费，只是对于非程序员或者普通用户来说，学习曲线有点陡峭。可能不容易操作。

所以我就帮大家Pass掉，直接推荐一个更好用的方案，跟着我操作，包你能看得明明白白，但你得有点耐心。设置完，以后也是一劳永逸，十分省心的。

3.1 腾讯云设置

3.1.1 注册账号

首先，你需要注册一个腾讯云账号。中国区网址是 https://console.cloud.tencent.com/cos，它支持多种登录方式，包括微信、QQ、邮箱等。
-

如果你没有注册过腾讯云，它会让你注册一个新账号。按照要求注册完成就好。

3.1.2 购买对象存储服务（COS）

登录之后，你需要购买一个对象存储服务（COS）。腾讯云COS的价格非常便宜，适合个人用户使用。

它的价格十分的便宜，按量付费。一般来说，一个月也就是几块钱。当时我还遇到了促销，结果只花了一块钱。现在这个配置，也就20块钱一年。

3.1.3 创建存储桶

接着，我们要进入到控制台（在界面右上角），然后在“存储桶列表”里，点击“创建存储桶”。给存储桶起个名字，选择私有读写，并且打开服务端加密。 请记下这里的名称、请求域名等信息。


3.1.4 获取API密钥

到访问管理页（https://console.cloud.tencent.com/cam/capi）里，**API 密钥管理**”，“创建密钥”，要记录 SecretID 和 SecretKey。

3.1.5 确定服务地址

你需要确认服务地址，**把桶名称从访问域名移除，才是你即将输入的服务地址。

假如你在腾讯云网站看到访问域名是 https://<bucket-name-with-number>.cos.<region>.myqcloud.com，那么“服务地址”是 https://cos.<region>.myqcloud.com.

例如我的服务地址就是：https://cos.ap-guangzhou.myqcloud.com。

如果之前你没有记录下来的话，你可以在存储桶的配置管理获取相关信息。

3.1.6 记下这些信息

  • 服务地址：例如 https://cos.ap-guangzhou.myqcloud.com
  • 存储桶名称：例如 obsidian-1302xxxxxx
  • SecretID
  • SecretKey
  • 存储区域：例如 ap-guangzhou

3.2 电脑端Obsidian设置

3.2.1 下载并安装Remote Save插件

打开Obsidian，选择你的库，然后点击左侧的设置图标，进入设置页面。在设置页面中，选择“社区插件”，然后点击“浏览”按钮，搜索“Remote Save”插件并安装它。

如果你无法访问社区插件，可以在我的公众号后台回复“Remote Save”获取插件的安装包。在之前的笔记里，有过相关的介绍，就不再一一赘述了。

3.2.2 配置Remote Save插件

启动插件，并跳转到配置页面。 根据如下图，选择远程服务：S3或兼容S3的服务。并把之前记下的信息，填入对应的字段。

配置好之后，点击检查，确认可以访问到存储桶。当看到”很好！可以访问存储桶“的提示时，就说明配置成功了。

#### 3.2.3 执行第一次同步设置

现在，你可以点击侧边栏的Remotely Save图标，执行第一次同步操作。这个过程可能需要一些时间，取决于你的笔记库的大小和网络速度。注意到后上角，会有开始同步的提示。

这时候，回到腾讯云的控制台，你就可以看到你的笔记文件已经上传到存储桶里了。

3.3 其他设备设置

3.3.1 在安卓设备上安装配置Remotely Save

我觉得在安卓平台上最简单的方式，应该就是直接从Google Play商店下载Obsidian应用安装完毕。

然后把安卓设备连接到电脑上，打开文件管理器，找到安卓设备的盘符。把Obsidian的仓库复制到安卓电脑里。

接着系统里打开Obsidian，直接打开这个仓库，第一次的同步就已经完成了。你会看见Remotely Saver也已经安装好了。

在安卓设备上，你可以直接创建新的笔记，编辑笔记，点击Remotely Save图标，就可以同步到腾讯云了。电脑端点击以下同步图标，很快就能同步下来。

3.3.2 在苹果设备上安装配置Remotely Save

苹果设备无法直接连接电脑传输文件，即使连接到电脑，我也只能查看照片而已。

所以在苹果设备上，直接从App Store下载Obsidian应用。然后，打开应用创建新库。同时安装并配置好Remotely Save插件。

点击Remotely Save图标，进行同步。这样，你的苹果设备也能和其他设备保持同步了。

3.3.3 关于苹果设备首次安装Remotely Save

你可能会说，苹果手机，我没有办法打开和安装社区插件，没有办法安装Remotely Saver，怎么才能实现第一次同步呢？这时候有2种选择：

  1. 科学上网，然后安装Remotely Save插件。
  2. 采用方案A，先在电脑端，把你的Obsidian库，直接复制到iCloud云盘里。然后在苹果设备上，从iCloud云盘打开这个库。最后配置好Remotely Save插件，就可以实现同步了。（我本身没有测试过这个方案，但我理论上觉得可行).

4 其他事项

4.1 同步频率

我们在刚才的演示中，采用的都是手动同步的方式。也就是说，每次你在某个设备上编辑完笔记后，需要点击Remotely Save图标，才能把修改同步到云端。

但是，如果你觉得手动同步麻烦，Remotely Save插件也支持自动同步功能。你可以在插件的设置页面中，找到自动同步选项，并根据你的需求进行配置。

4.2 启动后自动运行一次

另外还可以设置，每次启动Obsidian后，自动运行一次。这时候就能保证每次打开Obsidian的时候，都会自动同步一次，能从云端直接拉取最新的笔记。

4.3 主题和插件缺失

需要注意的是，默认情况下，Remotely Save插件只能同步你的笔记文件，而不会同步Obsidian的主题和其他插件设置。

所以，你需要在第一次同步的时候，同步配置文件夹。大家知道，配置文件夹都是放在.obsidian目录下的，开启再次同步，你就会发现云端多了一个.obsidian文件夹了。

但是，我通常只在第一次同步的时候，才会同步这个配置文件夹。然后我就会把这个选项关闭掉。毕竟，不同的设备，往往会有不同的插件需求和配置。例如在手机上，我会把大部分的插件都关闭掉，只保留最基本的功能。

5 结语

无论你是全家桶的苹果用户，还是多设备混合党，现在其实都有成熟的办法让 Obsidian 在各个平台里「一处修改，处处更新」。

  • 苹果党 → 用 iCloud，简单稳妥；
  • 混合党 → Remotely Save + 腾讯云 COS，更灵活也更省钱。

你可以对照上面的要点速览表，三分钟就能做出选择。接下来就是动手配置，让自己的笔记真正进入「随时随地可用」的状态。

无论你选择哪种方案，希望这篇文章能帮助你更好地管理和同步你的笔记库。如果在过程中遇到什么奇怪的问题，可以在评论区分享你的踩坑经验，说不定也能帮到后来的人。

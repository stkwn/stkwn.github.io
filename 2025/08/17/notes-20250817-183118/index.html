2 主要内容区域

2.1 什么是文件属性（Properties）

文件属性，通俗点讲，就是这篇文章的基本信息。如果你想象一下购物的快递单，就能明白。例如，每个包括都会写上收件人、地址、电话、快递公司等信息，这些信息让快递员能快速分拣和派送包裹。这些信息就是你快递的属性。

同样的，如果每篇笔记都能把一些重复的、重要的信息放在笔记前面，就能让你和Obsidian一眼看清笔记的“身份属性”。

比如，一篇读书笔记，总是有书名，作者，出版日期等信息。或者一篇日记，总是有日期、天气、心情等信息。这些信息就是文件属性。

Properties 文件属性就是给每篇笔记都贴上了“身份证”，让你的知识库变得井井有条，查找起来也更方便。

2.2 Properties 和Yaml的关系

Properties 文件属性是基于 Obsidian 的 YAML 语法来实现的。YAML 是一种数据序列化格式，常用于描述数据的格式，很多软件都用它来存储配置信息。

不过，对于很多刚接触 Obsidian 的小伙伴来说，手动写这些代码可能有点麻烦，容易出错（比如缩进、格式等问题）。于是，Obsidian 推出了 Properties 功能。

你可以把 Properties 理解为 YAML 的“可视化版本”——它把原本需要手动写的 YAML 信息，变成了一个简单的表格或者表单，你只需要点几下、填几个框，就能把这些属性加到笔记里了。

2.3 Properties 能做什么事情？

有了Properties文件属性，Obsidian知识库里的笔记就能变得更智能，更好用。简单来说，Properties 能帮你做到以下几点：

2.3.1 创建统一格式的笔记

针对同一类笔记，Properties 可以让你为每篇笔记添加统一的属性，通过模板可以快速的插入。比如标题、日期、标签等。这样，每篇笔记都有了自己的“档案”，方便查找。

2.3.2 分类、筛选和排序

Properties 可以让你对笔记进行分类、筛选和排序。我们可以根据不同的属性来筛选和查找笔记。例如，我想查找所有与“前端”相关的笔记，只需要在 Properties 里添加一个“tags”属性，然后在查询时筛选出“前端”标签的笔记即可。

2.3.3 配合插件实现自动化和高级查询

Properties 可以与 Obsidian 的其他插件配合使用，实现更高级的功能。例如，Dataview 插件可以读取 Properties 中的信息，帮你自动统计、汇总、展示符合某些属性的笔记。例如，你可以自动生成“本月学习总结”、“所有未完成的任务清单”等。

2.4 如何添加 Properties 文件属性？

在 Obsidian 中添加 Properties 文件属性非常简单。

2.4.1 通过属性面板添加

在笔记最上方，我们输入--- 后按下回车，就会出现一个属性面板。在这个面板中，你可以添加各种属性。

而之前输入的属性，可以快速的通过下拉菜单进行选择。

2.4.2 面板说明

在属性面板中，你可以看到它是分为左右两部分的，左边的部分是属性的名称和类型，右边是属性的值和描述。

  • 属性名称：也可以称为属性字段，是你想要记录的信息的名称。例如快递单上的“收件人”、“地址”、“电话号码等。

  • 属性类型：属性的类型决定了你可以输入什么样的数据。例如，文本类型可以输入任何文字，数字类型只能输入数字，日期类型只能输入日期等。每个属性名称都会对应一个属性类型。

    如图所示，当你输入一个属性名，可以点击旁边的按钮，这时候就可以选择属性的类型。

  • 属性值：这是你实际输入的信息。例如，如果属性名称是“收件人”，那么属性值就是你要填写的具体名字。

你可以通过这个面板来添加、修改或删除属性。每次修改后，Obsidian 会自动保存这些属性信息。

2.4.3 属性类型

Obsidian Properties 支持的类型主要有：

  • 文本：可以输入任何文字，比如“作者：小明”。
  • 数字：可以输入分数、数量等数字信息。
  • 日期：可以选择具体日期，比如“2024-06-10”。
  • 日期和时间：可以选择具体的日期和时间，比如“2024-06-10 14:30”。
  • 复选框：可以用来标记任务是否完成，比如“已读/未读”。
  • 列表：可以输入多个选项，比如“前端、JavaScript”。标签其实就是一种列表。

默认情况下，系统会为字符串输入分配文本类型，但同时也具备智能推断功能，能自动判定合适的数据类型。例如，若输入日期，系统可能会自动分配日期属性类型。

复选框则使用布尔类型。它的值就是true 或 false，其中true表示选中，而false表示未选中。

其中，列表类型相当于多选字段，例如您可以输入“PKM”后按回车键，即可看到它被添加为独立条目。这种类型特别适合需要同时选择多个值的场景，您还可以继续添加“Obsidian”、“YAML”之类的选项。

文本和列表类型的属性还可以包含 URL 和内部链接，使用[[链接]]语法即可插入。但是要注意必须用引号括起来。例如 "[[我的笔记]]"。

2.4.4 Obsidian的默认属性

Obsidian附带了一些默认的属性，主要有：

  • tags：用于标记笔记的标签。
  • aliases ：用于设置笔记的别名。
  • cssclasses ：使用css代码片段来为单个笔记设置样式。

Obsidian 的 Properties 就像是给你的笔记加上“表头”，你可以随时添加、修改、删除各种属性，让你的笔记信息更加丰富和有条理。

2.6 Properties 实用技巧和建议

2.6.1 结合模板自动化创建

Properties 可以与 Obsidian 的模板插件结合使用，实现自动化创建。你可以预先定义好一套属性模板，然后在新建笔记时自动插入这些属性。

例如，我上方展示的公众号文章模板，就预先定义好这些属性。这样每次写新文章时，只需要调用模板，就能自动生成这些属性。

2.6.2 使用推荐字段模板

常常回顾你的笔记时，你会发现有些属性是经常使用的。比如：

  • 读书笔记
    • book（书名）
    • author（作者）
    • date（读完日期）
    • rating（评分）
    • tags（标签：如 #小说、#技术）
    • publisher（出版社）
    • summary（摘要）
  • 学习笔记
    • topic（主题）
    • date（学习日期）
    • tags（标签：如 前端 Python）
    • source（学习来源：书籍，博客，视频）
    • status （状态：已完成，进行中）
    • url（相关链接）
    • resource （资源链接）
  • 工作笔记
    • project（项目名称）
    • date（日期）
    • status（状态：进行中，已完成）
    • priority（优先级：高，中，低）
    • tags（标签：如 #会议 #任务）
    • notes（备注）

你可以把这些常用的属性字段保存为模板，方便以后快速调用。这样就能避免重复输入，提高效率。

2.7 Properties 的常见问题

2.7.1 Properties 和 YAML 的区别是什么？

Properties 是 Obsidian 的一个新功能，它提供了一个更直观的方式来管理笔记的元数据。相比于传统的 YAML，Properties 更加易用，支持可视化编辑和动态更新。

你可以通过笔记右上角的三个点，切换到源码模式，查看 Properties 的 YAML 代码。

必须要注意的是：

  • YAML格式要求严格，比如缩进、冒号、引号等都要注意。新手容易因为格式错误导致 Obsidian 或插件无法识别。同时你看到的是一段代码，内容不太直观。
  • Properties则提供了一个可视化的界面，允许你通过点击和输入来添加和修改属性，避免了格式错误的问题。你看到的是一个表格或表单，内容一目了然，修改也很方便。

其实，Properties 是 Obsidian 对 YAML 的“包装”。你在 Properties 面板里添加的内容，Obsidian 会自动用 YAML 格式存到笔记的最顶部。你用的是前台，后台还是 YAML。

2.7.2 Properties支持多种语言吗？

是的，Properties 支持多种语言。你可以在属性名称和属性值中使用任何语言的字符。但是，为了确保兼容性，建议使用英文字符作为属性名称。

3 结语

今天对 Obsidian 的 Properties 文件属性做了一个简单的介绍。总而言之，Properties 让你的笔记变得更有条理，更易于管理和查询。

如果你还没有使用 Properties，那么现在就可以开始尝试了。翻看你的笔记，想想哪些信息是经常需要的，哪些信息是可以统一格式的，然后就可以开始添加 Properties 了。

Properties 和模板，可以说是初学者比较容易忽略的功能，但它们却能大大提升你的 Obsidian 使用体验。希望通过今天的介绍，大家能更好地利用 Properties 来管理自己的知识库。

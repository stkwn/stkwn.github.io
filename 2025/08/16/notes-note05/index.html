Obsidian完全入门之二：告别排版焦虑，用Obsidian一键发布公众号

发表于2025-08-16|更新于2025-08-16|notes
|浏览量:

1 缘起

前几天有位朋友对我说,：

你推荐的那个Obsidian软件，我都看不太懂呢，都是一堆术语，Markdown，插件，主题，一看就头大，看完我都不想用了。

这话把我给愣住了。是啊，我太习惯说专业术语了，完全没考虑到新手的感受。

但是如果因为这个原因，就让你错过了这么一款好软件，我觉得实在是太可惜了。

正因如此，我更觉得有必要好好介绍一下Obsidian——因为我自己就是从”排版焦虑症”患者变成”写作自由人”的活例子。

2 初识Markdown

我有一个朋友，是位职场经验非常丰富的经理人，每一篇公号文都是干货满满。

我特别喜欢阅读她的文章，可是这么有内涵的文稿，却被”颜值”给拖垮了。

她说，我也想提升呀，但是写文章已经耗尽了我的洪荒之力了……

记得我开始写公众号时，每次发文也一样经历这样的折磨：

  • 先在word里面绞尽脑汁写完内容
  • 复制到第三方排版网站
  • 确定标题，核对加粗，列表，字号……
  • 选择配色、样式、卡片
  • 上传插入图片等等
  • 小心翼翼复制到公众号
  • 检查发布

直到我遇见Obsidian和Markdown，我才发现：写作可以这么简单纯粹、发布可以这么高效丝滑……

2.1 让我们从原始的文本开始

今天早上，市场部的小明接到任务要写一份产品发布会邀请函。他打开Word，写道：

在Obsidian里，你也可以这么写，这就是原始的文本。

它没有任何排版，也看不出重点。

为了给它加上标题、加粗、列表等，你需要通过Word各类按钮进行排版格式。

2.2 利用Markdown，给文字披上衣服

Markdown 其实就是这样一套”文字穿衣法则“，只不过，它用一些固定的”符号” 来代替了鼠标的点击操作而已。例如：

  • # 标题 -> 标题
  • **加粗 -> 加粗
  • - 列表 -> 列表

它允许用户使用纯文本的格式编写文档，之后又非常方便有效的转化成 HTML 文档在各种网站上展示。

而用Word编写的文章，通过复制-粘贴到第三方平台，往往会失去格式，因此你不得不再次进行文本格式操作。

Markdown于2024年发布。这款“语言”就是希望降低文本格式化的难点，易于阅读、易于编写、易于网络流通使用 就是它风靡全球，成为最成功的标记语言的原因之一。

2.3 新手只需要学会的Markdown符号

2.3.1 标题

Markdown 语法适用符号 # 来确定标题。它一共分为了6个。

当我们为原文打上#和 ## 标签的时候，是不是一下子就清晰了很多呢？

2.3.2 强调、斜体、删除线和高亮

在写作时，我们最常用的几个格式功能，估计也是加粗、斜体、删除线和高亮了。

而在Markdown里都有对应的“语法配方”：

  • **我是加粗** -> 我是加粗
  • *我是斜体* -> 我是斜体
  • ~~我是删除线~~ -> 我是删除线
  • ==我是高亮== -> ==我是高亮==

2.3.3 列表和复选框

在写作时，我们经常需要列出各种事项，Markdown 提供了两种简单好用的”列表方式”：

1. 无序列表 - 自由随性的”便利贴”

用法：在每行开头输入 -

2. 有序列表 - 严谨的”待办事项”

用法：在每行开头输入 数字.

3. 复选框

在Markdown中，复选框就像给你的待办事项装上了”开关”，让清单变得可以互动：
用法： - [ ]和 - [x] 来表示。

通过tab键，可以进一步缩进。

让我们给原文打上这类标签，看看效果吧。

2.3.4 引用

在Markdown中，引用就像在笔记中插入一个个”对话气泡”，特别适合用来：

  • 标注重要观点
  • 记录他人发言
  • 突出关键内容

用法：>
同样的，它也只是嵌套 例如 > >> >>>, 只是很少使用而已。

2.3.5分割线

分割线常常用于分割写作中的内容块，使结构更清晰。

用法: ---

在我今天的文章中，我已经了很多分割线了。

2.3.6 图片、链接

Markdown通过以下的语法给出链接

  • 图片：![[xxx.png]]
  • 链接: [链接的文字](链接的地址)

但实际上，在Obsidian里，你可以截图之后，直接用ctrl+v 进行黏贴，它会自动存放在指定的文件夹中。

2.4 原始文本大变身

我相信，当你学完这几大符号，基本就满足日常的需要了。

复制一些漂亮的图标，让我们来看看最终的效果吧。

## 2.5 Markdown语法总结

Obsidian还有其他的语法，例如代码、表格等，可以有空的时候再去学习。

如果你实在记不得，也是没有关系的。 Obsidian 支持

  • 选择文字，右键菜单按钮，同样可以执行各种操作
  • 它同样也支持常用的快捷键，例如选择文字，通过ctrl+ b来实现加粗等。

3 Obsidian写作流

当你熟悉Markdown后，在Obsidian写作就会如行云流水般顺畅 – 那种手指始终在键盘上起舞的愉悦感难以言表：

  • 想加标题 #
  • 想加强调 ** **, 我还可以ctrl+B
  • 列清单：- 或1.

比起传统的写作，写稿 - 排版 - 修改循环，Markdown 写作者无需在键盘和鼠标间来回切换。这种专注的”心流状态” ，让你能够保持思维的连贯性、真正享受写作本身的乐趣。

你会惊讶的发现： 噢， 原来文字可以这么自然地流畅而出。

4 所见即所得，一键发布公众号

想象你的 Obsidian 是一个智能手机，插件就是你可以下载安装的”App”。

就像给手机装微信能聊天、装美团能点外卖一样，插件能给 Obsidian 添加各种新功能！

基础版的Obsidian就像自行车一样，能记笔记；装上插件，就变成了变形金刚了。

可以说，你能在拥有2400多款插件的社区插件市场里，找到你所需要的插件。

我的公众号文写作排版，就是利用夜半开发的MP Preview 插件，来实现一键复制粘贴到公众号发布的。

它真是好用到飞起。通常我会打开预览效果：

  • 左边是我的编辑区
  • 右边是我的实时预览区

所见即所得，当我完成所有的写作之后，只需要按下下方的按钮 复制到公众号 就可以进行发布了。所有的格式、图片都会实时同步过去。

5 结尾

希望我今天的Markdown之旅，可以让你发现它的美妙。

但这仅仅只是开始，Obsidian就像个百宝箱，它的强大和美妙还需要我们慢慢去挖掘。

让我们一切告别繁琐的格式工具箱，回归纯粹的写作，享受行云流水般码字的感觉。

先从简单的练习开始，一旦掌握，它会变成你终生的技能，再也回不去了。

跟我一起开始探索Obsidian的奇妙之旅吧。
